# Letterboxd → Кинопоиск

Расширение для Firefox: добавляет на страницу фильма в [Letterboxd](https://letterboxd.com) кнопку **Watch for free**, которая открывает этот же фильм на Кинопоиске (домен `.film`).

## Как работает

1. На странице фильма берёт ID IMDb и TMDB из ссылок внизу страницы.
2. По нажатию на кнопку запрашивает в [Wikidata](https://www.wikidata.org) ID Кинопоиска (свойство P2603).
3. Открывает `https://www.kinopoisk.film/film/<ID>/` в новой вкладке.
4. Если ID не найден, открывает поиск на `kinopoisk.ru`, переходит на первый результат и заменяет домен на `.film`.

## Установка для разработки

1. Склонируйте репозиторий.
2. В Firefox откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение…» и выберите `manifest.json`.

Требуется Firefox 140 или новее.

## Файлы

- `manifest.json` — манифест (MV2)
- `content.js` — добавляет кнопку на Letterboxd
- `background.js` — запрос к Wikidata и открытие вкладки
- `kp.js` — запасной вариант: переход с поиска Кинопоиска на страницу фильма
- `style.css` — стиль кнопки

## Приватность

Расширение не собирает и не хранит данные. Для поиска ID Кинопоиска оно отправляет ID открытого фильма (IMDb или TMDB) в публичный сервис Wikidata.
